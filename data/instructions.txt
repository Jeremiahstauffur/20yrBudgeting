To use this website or Android app offline and online:
1. Open start.html in any modern web browser, or install the Android app from the `android/` project (`com.twentyyearbudgeting.app`).
2. First Login & Biometrics: On your first visit, sign in with your Username and Password. Afterwards, you can log in with a single tap using your phone's Biometrics (fingerprint / face unlock).
3. Offline + Online Railway Sync: All data is saved automatically to local storage on your phone/browser AND synced automatically to the Railway database when online (`server/index.js`).
4. Conflict Resolution: If two users make conflicting offline changes to the same item, the system automatically accepts the changes of whichever user logged in FIRST EVER before the other user (tracked via `firstLoginOrder` / `firstLoginAt`).
5. Bottom Navigation Bar: Use the bottom navigation bar with icons to switch between Home, Banking, Paycheck, Scan, and Report pages.
6. Backups: Use the Gear icon (⚙️) in the bottom right corner to configure your Railway API URL, lock the app for biometrics, or Export/Import JSON backups.
